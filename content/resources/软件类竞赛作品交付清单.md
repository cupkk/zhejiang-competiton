# 软件类竞赛作品交付清单

适用于计算机设计、软件杯、物联网、信息安全及项目类编程竞赛。

## 可运行版本

- [ ] 从干净环境按文档完成一次部署。
- [ ] 固定运行时、依赖和数据库版本。
- [ ] 准备最小测试账号与测试数据，不包含真实个人信息。
- [ ] 网络、模型或第三方服务不可用时有明确提示或演示备份。

## 交付目录

- [ ] `README` 写清环境、启动步骤、账号和已知限制。
- [ ] 源代码不包含密钥、密码、访问令牌和生产数据库。
- [ ] 数据、模型、字体、图片和音视频注明来源及授权。
- [ ] 设计文档、测试记录、演示视频和答辩文件使用一致版本号。

## 演示

- [ ] 三分钟内能完成核心流程。
- [ ] 首屏直接展示问题、对象和当前结果。
- [ ] 准备正常、空数据、错误和弱网状态。
- [ ] 关键指标能追溯到测试方法和原始记录。

## 提交前

- [ ] 逐项对照具体赛道的文件名、大小、格式和匿名要求。
- [ ] 用另一台电脑打开最终压缩包并运行。
- [ ] 保存提交页面、时间和文件哈希。
- [ ] 团队成员共同确认最终版本，停止临时替换文件。

本清单是平台原创通用模板。具体材料仍按所参加赛道的正式通知拆分。
