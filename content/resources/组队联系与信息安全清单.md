# 组队联系与信息安全清单

## 发布前

- [ ] 写清竞赛、项目阶段、缺少角色和每周投入。
- [ ] 联系方式只填写本人愿意公开的微信号、手机号或邮箱。
- [ ] 不上传身份证、学生证、成绩单和含家庭住址的文件。
- [ ] 示例、测试项目和真实招募要明确区分。

## 初次联系

- [ ] 先确认对方学校、能力、时间和参赛目标。
- [ ] 用文字记录分工、交付物和退出方式。
- [ ] 不因“保留名额”“内部渠道”提前转账。
- [ ] 不把账号密码、验证码、API 密钥交给队友。

## 开始协作

- [ ] 使用团队共享目录，不使用个人桌面作为唯一副本。
- [ ] 代码和文档保留版本记录。
- [ ] 明确数据、作品和知识产权归属。
- [ ] 涉及企业、实验室或未公开数据时先取得授权。

平台只提供同校公开信息展示，不提供私聊、担保、代收款或身份材料托管。发现虚假招募、骚扰、收费或侵权内容时，可在详情页举报并停止联系。
