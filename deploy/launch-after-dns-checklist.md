# 备案通过后的上线执行清单

> 历史说明：本文档保留早期上线过程。2026-07-26 起以 `deploy/internal-beta-release-gates-20260726.md` 为准；其中“暂不轮换密钥”的旧决定已经失效，曾暴露的微信 AppSecret 必须轮换。

日期：2026-04-30

## 当前前提

- 备案已通过。
- 用户决定暂不轮换 OSS Key、微信 AppSecret、管理员密码。
- 当前产品继续以 H5 主线为准，最快的小程序上线方式是用一个轻量微信小程序壳承载 H5。
- 微信支付继续暂缓，用户端不展示购买、支付、退款入口。

## 当前必须确认

1. 域名解析
   - `campusgrow.top` 或正式子域名必须 A 记录指向 `121.43.58.9`。
   - 当前正式域名确定为 `campusgrow.top`，`www.campusgrow.top` 可作为跳转域名。

2. HTTPS
   - 小程序 request 合法域名和 web-view 业务域名都必须是 HTTPS。
   - 不能用 `http://121.43.58.9` 提交小程序审核。

3. 真实微信登录
   - 线上 `WECHAT_LOGIN_MODE` 必须从 `hybrid` 切到 `real`。
   - 前端不能继续依赖 `demo-code` 快速登录。
   - 小程序壳需要调用 `wx.login` 获取 code，再交给后端 `/api/auth/wechat/login`。

4. 小程序后台配置
   - 配置 request 合法域名：`https://正式域名`。
   - 如果用 `web-view`，配置业务域名：`https://正式域名`。
   - 上传微信要求的域名校验文件到站点根目录。
   - 完成用户隐私保护指引。

## 你需要做的事

1. 在 DNS 控制台确认解析记录已经生效。
   - 主机记录：`@` 或 `app`
   - 记录类型：`A`
   - 记录值：`121.43.58.9`

2. 在微信公众平台确认小程序基础资料。
   - 小程序名称、头像、简介、服务类目。
   - 隐私保护指引。
   - AppID / AppSecret 当前是否仍有效。

3. 提供微信后台下载的业务域名校验文件。
   - 文件名通常类似 `MP_verify_xxxxx.txt`。
   - 这个文件需要部署到 H5 域名根目录，确保 `https://域名/MP_verify_xxxxx.txt` 可访问。

4. 正式访问域名已经确定。
   - 用户端：`https://campusgrow.top`
   - 后台：`https://campusgrow.top/admin`

## 我可以直接帮你做的事

1. 服务器配置
   - 检查 DNS 是否解析到 `121.43.58.9`。
   - 配置 Nginx 正式域名。
   - 申请和安装 HTTPS 证书。
   - 把 HTTP 自动跳转到 HTTPS。

2. 后端生产配置
   - 更新 `/etc/campus-growth/api.env`。
   - 将 `API_PUBLIC_ORIGIN` 切到正式域名。
   - 将 `WECHAT_LOGIN_MODE` 切到 `real`。
   - 重启 API 并验证 `/api/health`。

3. 前端代码
   - 去掉 `demo-code` 快速登录。
   - 增加微信小程序环境下的真实登录入口。
   - 清理页面残留乱码、开发态文案、支付相关入口。
   - 构建并部署新版 H5。

4. 小程序壳
   - 新建最小微信小程序工程。
   - 使用 `web-view` 承载 H5。
   - 增加登录 code 传递方案。
   - 生成可用微信开发者工具打开的工程目录。

5. 上线验收
   - 做游客、首登、资料补全、收藏、资源下载、组队申请、发帖、消息、后台审核冒烟测试。
   - 输出提交微信审核前检查表。

## 不轮换密钥的风险记录

用户已明确决定暂不轮换密钥和管理员密码。继续上线可以推进，但需要接受以下风险：

- 曾经出现在对话或文件里的 OSS Key、AppSecret、管理员密码可能已经不再完全私密。
- 如果上线后出现异常登录、对象存储异常访问、后台异常操作，第一处置动作仍然会是立即轮换密钥和密码。
- 正式推广前仍建议至少把管理员密码改成非默认强密码。
